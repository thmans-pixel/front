# Cahiers des charges (specs)

Une spec par étape ou par chantier : `NNN-titre.md` (001, 002…).

Statuts possibles, indiqués en tête de chaque spec :

- **brouillon** — en discussion, on ne code pas ;
- **validée** — Thibault l'a acceptée, on peut la réaliser ;
- **réalisée** — le code est fusionné sur `main` ;
- **abandonnée** — gardée pour l'historique.

Chaque spec contient : contexte, règles précises avec valeurs, critères
d'acceptation testables, maquettes des écrans touchés, risques et questions
ouvertes. Ce qui touche les enfants est signalé « 🔒 gardien-enfants ».
